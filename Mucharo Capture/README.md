# Mucharo Capture

Copy the `reframework` directory from this package into the Street Fighter 6 installation directory. Keep `mucharo_capture.lua` and the `MCA` subdirectory together under `reframework/autorun`.

Mucharo Capture v3.8.3 exports replay observations to `reframework/data/replay/`. Its window offers **Save (Full Speed)** and **Save (Background)**. Auto-Record queues unsaved captures when starting the next recording.

This package mirrors the Lua files from [sf6-ai-coach at 4ed7af8](https://github.com/yulgi/sf6-ai-coach/tree/4ed7af8cb5e1a0ba6be35a8ac8077d2ea4462a14/scripts). The capture script is based on [mucharo-sf6-capture](https://github.com/mkstksf6/mucharo-sf6-capture).
